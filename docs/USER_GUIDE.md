# 利用者マニュアル — Discord Webhook Manager for CMK

対象: WebUI から Discord への告知を送る人

アクセス先: **https://dwm-pkg-v2.tesatech.net**

## 1. ログイン

管理パスワードを入力するだけです。アカウントの概念はなく、全員が同じ「管理者」として操作します。
ログイン状態は7日間保持されます。

> パスワードを何度も間違えると、そのネットワークから15分間ログインできなくなります。
> 分からなくなったら管理者に問い合わせてください。

## 2. 画面の構成

| メニュー | できること |
|---|---|
| **ダッシュボード** | 待機中・送信済み・失敗の件数、予約一覧、直近の送信 |
| **送信** | メッセージを作って即時送信または予約 |
| **Webhook** | 送信先の登録・編集・テスト送信 |
| **送信履歴** | 過去の送信の確認、キャンセル、再送 |
| **定期実行** | cron による繰り返し送信 |
| **APIキー** | 外部システム連携用のキーの発行・失効 |
| **設定** | 失敗アラートの通知先、パスワード変更、操作ログ |

表示される時刻はすべて **日本時間（JST）** です。

## 3. まず送信先を登録する（Webhook）

送信先は毎回 URL を貼るのではなく、名前を付けて登録しておきます。

### 3-1. Discord 側で Webhook URL を取得

1. 投稿したいチャンネルの **⚙ 編集** → **連携サービス** → **ウェブフック**
2. **新しいウェブフック** を作成し、**ウェブフックURLをコピー**

### 3-2. 本システムに登録

「Webhook」画面の下部フォームに入力します。

| 項目 | 説明 |
|---|---|
| **name**（必須） | 識別子。英小文字・数字・ハイフン。例 `cmk-announce`。API からもこの名前で指定します |
| **表示名** | 人が読む名前。例「準備会 お知らせチャンネル」 |
| **Webhook URL**（必須） | コピーした URL |
| 既定の表示名 / アイコン URL | 送信時に毎回指定しなくてよくなります |
| 既定のスレッドID | フォーラムチャンネルなどに投稿する場合のみ |
| タグ | 分類用。任意 |
| メモ | 用途や担当者など |

登録すると URL は暗号化されて保存され、**以降どこにも表示されません**（`.../webhooks/1398…56/••••wXyZ`
のようなマスク表記のみ）。URL を変更したいときは編集画面で新しい URL を入れて上書きします。

### 3-3. テスト送信

一覧の「テスト送信」ボタンで、そのチャンネルに確認用メッセージが1通届きます。登録直後に一度
押しておくと安心です。

## 4. メッセージを送る（送信）

### 4-1. 宛先

「登録済み webhook から選ぶ」か「Webhook URL を直接指定」を選びます。普段は前者を使ってください。

### 4-2. 本文

- **content**: プレーンテキスト（2,000字まで）。改行はそのまま反映されます
- **Embed**: 「＋ Embed を追加」で枠を追加します。最大10個

Embed で設定できるもの:

| 項目 | 内容 |
|---|---|
| タイトル / 本文 | 見出しと説明文 |
| タイトルのリンク先 URL | タイトルをクリックできるようにする |
| 左端の色 | カラーピッカーか `#RRGGBB` |
| 著者名 / 著者アイコン | 上部の小さな行 |
| サムネイル画像 URL | 右上の小さい画像 |
| 大きい画像 URL | 下部の大きい画像 |
| フッター文言 | 下部の小さい文字 |
| 送信時刻を表示 | フッター右に時刻を出す |
| フィールド | 「名前 + 内容」の組。横並びにすると1行に最大3つ並びます |

右側の**プレビュー**が入力に合わせてリアルタイムで更新されます。送信前に必ず確認してください。

> 画像はサーバーにアップロードするのではなく、**すでにインターネット上にある画像の URL** を
> 指定する方式です。Discord に貼った画像を右クリック →「リンクをコピー」でも取得できます。

**JSON を直接編集**にチェックを入れると、Discord のペイロードをそのまま編集できます。他所で
作った JSON を貼り付けたいときや、定期実行用の JSON を用意したいときに便利です。

### 4-3. オプション

| 項目 | 説明 |
|---|---|
| 表示名 / アイコンの上書き | この1通だけ送信者名を変える |
| スレッドID | 特定のスレッドに投稿する |
| **@everyone / ロールメンションを有効にする** | **既定はオフ**。オフのままなら本文に `@everyone` と書いても誰にも通知されません。意図して全体通知したいときだけオンにしてください |
| 通知なしで送信する | メッセージは投稿されますが通知音・バッジが出ません |

### 4-4. 送信タイミング

- **今すぐ送信**: 数秒以内に届きます
- **日時を指定して予約**: 日本時間で指定します。時刻になると自動で送信されます

「送信する」を押すとジョブ詳細画面に移り、結果が確認できます。

## 5. 送信の確認・取り消し（送信履歴）

一覧の状態バッジ:

| バッジ | 意味 |
|---|---|
| **待機中** | これから送る（予約またはリトライ待ち） |
| **送信中** | Discord へ送信している最中 |
| **送信済み** | 正常に届いた |
| **失敗** | 送れなかった |
| **キャンセル** | 送信前に取り消した |

ジョブIDをクリックすると詳細が見られます。詳細画面でできること:

- **キャンセル**: 待機中のものを取り消す
- **今すぐ再送する**: 失敗したものをもう一度試す
- **この内容で新規作成**: 同じ内容を送信画面に読み込む（毎月の定例告知などに便利）

### 失敗したときの見方

詳細画面の赤い枠にエラーが出ます。

| 表示 | 原因と対処 |
|---|---|
| `HTTP 404: Unknown Webhook` | Discord 側で Webhook が削除されています。Discord で作り直し、Webhook 画面で URL を差し替えてください |
| `HTTP 401 / 403` | Webhook のトークンが無効です。同上 |
| `HTTP 400` | 内容が Discord に拒否されました。文字数超過や画像 URL の誤りが多いです |
| `misfire` | サーバーが長時間停止しており、予定から24時間以上過ぎたため送りませんでした。必要なら作り直してください |
| `named webhook が削除されています` | 宛先の登録が消えています |

一時的なエラーは自動でリトライされます（最大5回、2時間ほどかけて）。それでも駄目だった場合のみ
「失敗」になります。

## 6. 繰り返し送る（定期実行）

「毎週月曜の朝9時に定例のお知らせ」のような繰り返しを登録できます。

1. **名前**: 分かりやすい名前
2. **cron 式**: `分 時 日 月 曜日` の5つを空白区切り（日本時間で解釈されます）
3. **宛先 webhook**
4. **payload JSON**: 送信画面の「JSON を直接編集」で組み立てて貼り付けるのが簡単です

cron 式の例:

| 式 | 意味 |
|---|---|
| `0 9 * * 1` | 毎週月曜 9:00 |
| `30 8 1 * *` | 毎月1日 8:30 |
| `0 12 * * 1-5` | 平日の毎日 12:00 |
| `*/30 * * * *` | 30分ごと |
| `0 10 25 12 *` | 毎年12月25日 10:00 |

登録すると次回実行時刻が表示されます。一時的に止めたいときは「停止」、不要になったら「削除」です。
定期実行から生まれた送信も、通常どおり送信履歴に残ります。

## 7. 外部システムから送る（APIキー）

サイトや Bot、AI エージェントからこのサーバー経由で送信させたいときは、API キーを発行して渡します。

1. 「APIキー」画面でラベル（渡す相手が分かる名前）を入力
2. スコープを選ぶ
   - **send**: 送信のみ
   - **send + manage**: webhook や定期実行の登録もできる
3. 「Webhook URL の直接指定を許可する」は、必要なければ**オフ**にすると安全です
   （登録済み webhook 宛にしか送れなくなります）
4. 発行するとキーが**一度だけ**表示されます。その場でコピーして相手に安全な方法で渡してください

不要になったキーは「失効させる」を押せば即座に使えなくなります。渡した先での実装方法は
[AI 向け連携メモ](AI_INTEGRATION.md) を共有してください。

## 8. 設定

- **失敗アラートの通知先**: 送信に失敗したときに通知を受け取る named webhook。運用チームの
  チャンネルを指定しておくと、告知が届いていないことにすぐ気づけます
- **管理パスワードの変更**: 変更すると全員が一度ログアウトされます
- **操作ログ**: 誰がいつ何をしたかの記録

## 9. よくある質問

**Q. 送信を取り消したい（もう届いてしまった）**
A. 本システムからは削除できません。Discord 側でメッセージを削除してください。

**Q. 予約した内容を修正したい**
A. 直接の編集はできません。ジョブ詳細で「この内容で新規作成」→ 修正して予約し直し →
元のジョブをキャンセル、という流れが確実です。

**Q. 画像を添付したい**
A. ファイル添付には対応していません。画像をどこか（Discord の別チャンネルなど）にアップロードして
その URL を Embed の画像欄に指定してください。

**Q. 予約した時間ぴったりに届く？**
A. 5秒程度の誤差が出ます。秒単位の精度が必要な用途には向きません。

**Q. サーバーが止まっていた間の予約はどうなる？**
A. 24時間以内なら復旧後に送信されます。それを超えたものは「大幅に遅れた告知」を防ぐため送信されず、
失敗として記録されます。

**Q. 同じ内容を複数のチャンネルに送りたい**
A. 現在は1ジョブ1宛先です。宛先を変えて複数回送信してください。
